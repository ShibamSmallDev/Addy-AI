# Chesta Companion Addon

A planned **Minecraft Bedrock Edition** add-on: a wholesome anime-style companion
NPC named "Chesta," explicitly designed as **not** romantic/NSFW — the design brief
states this directly.

## Character design
Large expressive eyes, long dark-indigo hair with violet highlights, golden amber
eyes, silver moon-shaped hairpin; oversized black hoodie with purple accents;
purple/black/silver color theme. Personality: loyal, friendly, slightly clingy,
protective, curious, playful, supportive.

## Planned features
- Custom entity with spawn egg and survival-compatible spawning.
- "Follow Me" / "Stay Here" interaction commands.
- A friendship-points system with levels.
- Full Behavior Pack + Resource Pack structure (manifests, entities, animations,
  scripts, dialogue, textures, models, sounds, UI).

Drafted 2026-06-17 (*Chesta Companion Addon Plan*). Interesting contrast with
